# 大学生学习互助平台 - MVP页面原型设计

## 一、整体架构设计

### 1.1 用户角色与权限

| 角色 | 核心功能 | 访问范围 |
|------|----------|----------|
| **学生** | 搜索课程、查看导师、加入课程群、管理订单 | 首页、课程搜索、导师列表、课程群详情、我的订单 |
| **导师** | 创建课程群、上传资料、管理学生、查看收益 | 课程群管理、资料管理、学生管理、收益统计 |
| **个人中心** | 学校认证、我的课程、我的评价、账户设置 | 认证中心、课程列表、评价管理、个人资料 |

### 1.2 路由设计

```
/                              # 首页（公共）
/login                         # 登录页（公共）
/register                      # 注册页（公共）

# 学生端路由
/groups                        # 课程群列表（搜索课程）
/groups/:id                    # 课程群详情（资料+答疑）
/tutors                        # 导师列表
/tutors/:id                    # 导师详情
/orders                        # 我的订单

# 导师端路由
/tutor/manage                  # 导师工作台
/tutor/groups                  # 课程群管理
/tutor/groups/create           # 创建课程群
/tutor/materials               # 资料管理
/tutor/students                # 学生管理
/tutor/earnings                # 收益统计

# 个人中心路由
/profile                       # 个人中心首页
/profile/certify               # 学校认证
/profile/courses               # 我的课程
/profile/reviews               # 我的评价
```

## 八、设计规范

### 8.1 色彩方案

| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主色调 | #5B8FF9 | 品牌蓝色，用于主按钮、链接、强调 |
| 成功色 | #61DDAA | 绿色，用于成功状态、通过审核 |
| 警告色 | #F6BD16 | 橙色，用于警告、待处理 |
| 危险色 | #F54A45 | 红色，用于删除、拒绝、封禁 |
| 中性色 | #1F2937 ~ #F9FAFB | 文字和背景层次 |

### 8.2 字体规范

- 中文字体：PingFang SC / Microsoft YaHei
- 英文字体：Inter / Roboto
- 标题：18-24px，字重600-700
- 正文：14-16px，字重400-500
- 辅助文字：12-13px，字重400

### 8.3 间距规范

- 卡片间距：16-24px
- 内容间距：8-16px
- 页面边距：16-24px（响应式）

### 8.4 组件规范

- 按钮高度：40-48px
- 输入框高度：40-48px
- 卡片圆角：12-16px
- 阴影：0 4px 6px -1px rgba(0, 0, 0, 0.1)

## 九、交互细节

### 9.1 通用交互

- 按钮悬停：颜色加深10%，微缩放效果
- 卡片悬停：阴影加深，上移2px
- 表单验证：实时反馈，错误提示红色边框
- 加载状态：按钮置灰，显示loading动画

### 9.2 特殊交互

- 课程群加入：弹窗确认，显示群费信息和支付方式
- 资料下载：点击后显示下载进度
- 评价评分：点击星星选择评分，实时预览
- 认证提交：提交后显示审核状态，审核完成后通知用户
- 订单支付：支持微信/支付宝支付，支付成功后自动加入课程群

### 9.3 响应式适配

- 移动端：单列布局，底部导航
- 平板端：双列布局
- 桌面端：三列布局，完整功能展示
